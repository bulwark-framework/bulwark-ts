# Frontend

No frontend exists or is planned in this repository. Interaction surfaces are:

- CLI (`bulwark compile`, `bulwark approve`, `bulwark assess`), proposed, see [ARCHITECTURE.md](../ARCHITECTURE.md).
- Registry HTTP API, proposed, see [design-docs/question-set-registry.md](design-docs/question-set-registry.md).
- Assessor review surface: out of scope here. A deployment supplies its own UI over the child workflow's Signals and queries.
